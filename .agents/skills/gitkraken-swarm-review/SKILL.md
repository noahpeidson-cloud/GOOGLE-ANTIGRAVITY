# GitKraken Swarm Code Review Skill

## Overview
Provides the operational procedure for Antigravity agents to inspect branches and audit pull requests generated by terminal CLI agents (Claude Code) using GitKraken MCP tools.

## Tool Chain & MCP Mapping
This skill leverages the lazily loaded `GitKraken` MCP server:
- `call_mcp_tool(ServerName="GitKraken", ToolName="git_status", Arguments={})`: Verify active branch and modified files.
- `call_mcp_tool(ServerName="GitKraken", ToolName="git_log_or_diff", Arguments={"revision": "feat/my-branch..main"})`: Inspect exact commit diffs.
- `call_mcp_tool(ServerName="GitKraken", ToolName="git_blame", Arguments={"path": "filepath"})`: Check historical authorship.
- `call_mcp_tool(ServerName="GitKraken", ToolName="pull_request_get_detail", Arguments={...})`: Inspect PR metadata and comments.

## Review Workflow

### 1. Identify Scope & Ground Truth
Do not review a bare diff in isolation. Run `git_status` and `git_branch` via GitKraken MCP to confirm the target branch.

### 2. Measure the Full Context
For every diff hunk touching logic, error handling, or security boundaries, read the full surrounding file. 

### 3. What to Flag (Zero-Discretion Standard)
- **Correctness bugs:** Logic flaws, off-by-one errors, unhandled exceptions, race conditions, broken imports.
- **Security vulnerabilities:** Hardcoded credentials, path traversal, shell injection.
- **Wasteful operations:** Unbounded quadratic loops, memory leaks, un-indexed database queries.

### 4. Verification Before Reporting
Verify every potential finding against the live disk before outputting. State the exact trigger: `[Input / State] -> [Crash / Wrong Output]`.
