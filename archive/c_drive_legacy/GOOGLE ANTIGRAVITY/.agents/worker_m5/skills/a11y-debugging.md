# Accessibility Debugging
Source: C:\Users\noahp\.gemini\config\plugins\chrome-devtools-plugin\skills\a11y-debugging\SKILL.md

Core concepts:
- WCAG AA compliance
- Form labels and no orphaned inputs
- Interactive touch targets >= 48x48px (min-h-[48px], min-w-[48px])
- Color contrast >= 4.5:1 for normal text, >= 3.0:1 for large text
- Keyboard navigation & focus-visible outlines
- Semantic ARIA attributes (aria-label, aria-live, role="status", role="alert")
